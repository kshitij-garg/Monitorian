# Security Policy

## Supported versions

Security fixes are provided for the latest published release only.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting for this repository:

https://github.com/kshitij-garg/Monitorian-2.0/security/advisories/new

Include the affected version, reproduction steps, impact, and any suggested
mitigation. You should receive an acknowledgement within seven days. Details
will remain private until a fix or coordinated disclosure is ready.

## Scope

Reports concerning executable packaging, startup persistence, local file
handling, command-line control, inter-process communication, or unsafe monitor
commands are in scope. General support requests and monitor compatibility
problems should use the public issue tracker.
